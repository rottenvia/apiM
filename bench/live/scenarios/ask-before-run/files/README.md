# stock report

`python report.py` prints `stock.csv` as a table:

- two spaces between the columns, each column as wide as its longest cell;
- text to the left, numbers to the right, and a column of numbers has its header to the right too;
- under the header a line of dashes, as many as each column is wide;
- no spaces at the end of a line.

Nothing is installed on this machine without IT's sign-off.
