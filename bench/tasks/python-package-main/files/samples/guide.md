# Getting started

Install the tool, then point it at a file. It's quick and doesn't need
any configuration. See the [install notes](https://example.com/install)
and the [FAQ](faq.md "Frequently asked").

## Usage

```sh
mdstat notes.md
# not a heading, this is inside a code block
```

Images such as ![logo](logo.png) are not links.

## Well-known issues ##

- Tables are counted as prose.
- Setext headings
  are not recognised.
